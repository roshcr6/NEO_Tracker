# Asteroid Smash Game

An educational space-themed arcade game where players defend Earth from asteroids while learning about space!

## Features

- **Retro pixel-art graphics** - Classic arcade-style visuals
- **Educational quiz system** - Answer space trivia questions for extra lives
- **Invincibility power-up** - Correct answers grant 5 seconds of invincibility
- **High score tracking** - Compete with yourself and improve
- **Space facts** - Learn interesting facts about asteroids and space
- **Smooth animations** - Polished transitions and effects

## How to Play

1. Open `AsteroidSmash/index.html` in your web browser
2. Click **PLAY** to start the game
3. **Controls:**
   - **Move:** Arrow Keys or A & D
   - **Shoot:** Space or Left Mouse Click
4. Defend Earth by shooting incoming asteroids
5. You have 3 hearts - don't let asteroids hit Earth!
6. When you lose all hearts, answer a space quiz question correctly to continue with an extra life
7. **Game Over Options:**
   - Press **R** to restart immediately
   - Press **E** to return to the main menu

## Game Mechanics

- **Lives:** You start with 3 hearts
- **Quiz System:** When you run out of lives, you have 5 seconds to answer a space trivia question
  - Correct answer: +1 heart + 5 seconds invincibility
  - Wrong answer: Game over
- **Invincibility:** During invincibility, your ship blinks and asteroids won't damage you
- **Difficulty:** Asteroids spawn at varying speeds and sizes for balanced challenge
- **High Score:** Your best score is saved locally

## Educational Value

Perfect for kids and space enthusiasts! The game teaches:
- Solar system facts
- Asteroid and planet information
- Space exploration history
- Astronomical concepts

## Technical Details

- Pure JavaScript (no frameworks required)
- HTML5 Canvas for rendering
- Web Audio API for sound effects
- LocalStorage for high score persistence
- Responsive pixel-perfect scaling
